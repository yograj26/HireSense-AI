# 5-minute demonstration script
1. Launch Streamlit at localhost:8501.
2. Select a demo job (Junior Data Scientist, ML Engineer, or Data Analyst).
3. Show required/preferred skills and job description.
4. Show ranked synthetic candidates.
5. Inspect one candidate: matched skills, missing skills, preferred skills, score and explanation.
6. Upload PDF, TXT or DOCX resume and show parsed skill evidence.
7. Use Resume Analyzer to extract skills from pasted text.
8. Use Analytics and export screening results CSV.
9. Open API Swagger at localhost:8000/docs and test health and match.
10. Import postman/SmartHire_API.json and execute requests.
11. Run pytest and show Docker Compose and Jenkinsfile.
